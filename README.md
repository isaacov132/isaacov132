## 🚀 Proyectos Destacados

* **AutoTech Manager:** Aplicación web full-stack para la gestión de talleres automotrices. Backend estructurado en Java Spring Boot, frontend en React Vite, generación automatizada de facturas PDF mediante Mailtrap y persistencia relacional en Supabase.
* **ParabolicLab:** Plataforma de simulación de laboratorio virtual para física (proyecto de titulación). Desarrollado con una arquitectura orientada a servicios usando Python FastAPI en el backend y React Next.js en el frontend.
* **Gauss-Jordan Academy:** Aplicación web educativa enfocada en álgebra lineal. Permite crear matrices y resolverlas con manejo de estado en tiempo real, construida con React, TypeScript y Tailwind CSS.
* **OptiPDF:** Herramienta web *on-premise* para la gestión y manipulación de documentos PDF. Implementada con un núcleo de FastAPI y `pikepdf`, interfaz en Next.js y orquestación local de PostgreSQL usando Docker.
